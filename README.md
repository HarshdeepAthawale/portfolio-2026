# Harshdeep Athawale - Portfolio

My personal site, built to feel like the Minecraft title screen. Pick a menu option to see where I've worked, what I've built, what I'm learning, and what I write about.

I'm a security researcher and Computer Engineering student at Thapar. Most of my time goes into finding bugs in real systems and building tools to stop them.

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Most of the content lives in `content/` and can also be edited from `/admin`.
